In this branch of the mechanicat-oramods repository are the files for one of my OpenRA modifications, the Red Alert GLA mod that is based on red-alert-release-20250330.
This mod is a work in progress, while considered playable in its current condition, everything included in it can be subjected to change as the idea behind the modification evolves.

The aim of this modification is to add a third side to the Red Alert theatre of war. This new side is loosely inspired from the GLA faction in C&C Generals, hence the name of the modification.
It is not meant them to be a copy of the original faction, more like an adaptation of it to the system of Red Alert 1, so there are noticeable differences in the faction structure.
Many things are custom or straight up invented for purposes of the mod.
