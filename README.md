In this branch of the mechanicat-oramods repository are the files for a simple modification that allows kknd style production to be used on any map of the Red Alert mod. 
This production type enable multiple items can be built in parallel within each production queue at the same time.

it is based on red-alert-release-20250330 and does not include any other changes.
also available in map-mod form, that can be found here:
https://resource.openra.net/maps/67414/
