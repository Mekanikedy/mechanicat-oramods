In this repository are the files of my OpenRA modifications. 

rab - Red Alert B mod. Adds some more playable countries to RA. 
cnc2k - TD 2000 mod. Tech-tree changes to work like in D2K via upgrades. 
cncsubf - TD Subfactions mod. Defines 5 playable subfactions per side.
